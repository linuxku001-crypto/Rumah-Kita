# Sahrul ♥ Dara — Ruang Kita 🤍
Website privat untuk kita berdua.

## Upload ke GitHub Pages
1. Buat repository baru bernama `sahrul-dara` (Public).
2. Upload semua file & folder (Add file → Upload files). Video masuk ke `assets/video/kereta-senja.mp4`.
3. Settings → Pages → Branch: `main`, folder: `/ (root)` → Save.
4. Tunggu 1–2 menit, buka: https://USERNAME-KAMU.github.io/sahrul-dara/

## Supaya login Google aktif
Di Google Cloud Console → APIs & Services → Credentials → pilih Client ID kamu:
- Authorized JavaScript origins: tambahkan
  `http://localhost` dan `https://USERNAME-KAMU.github.io`
- Save. Tunggu beberapa menit.

## Catatan
- Ganti email Dara di `assets/js/config.js`.
- Jangan pernah upload "client secret" ke GitHub. Client ID aman.
